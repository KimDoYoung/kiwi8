# 기준가

## 요약

**기준가를 가지고 매도 타임을 잡는다.**

### 프롬프트

 base_price 를 고려하고 있음. 이것이 무엇이냐하면 기준가격이라는 것이지. 즉 주로 매도의 기준을 잡기 위한 것임.
 가격이 100, 150, 130,120,160 이렇게 변화할때
 base_prcie는 100, 150, 150, 150, 160 이렇게 변화하는 것임.
  
 그래서 base_price의 15% 이하로 떨어지면 매도타임으로 잡으려고 함.
 매수는 아직 고려하지 않음.
